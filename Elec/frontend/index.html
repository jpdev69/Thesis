BS Computer Science thesis system

Campus energy forecasting, with the evidence visible.

EnergyAI produces daily campus electricity forecasts from billing-derived consumption, Open-Meteo weather, and academic schedule context using a cascaded attention-LSTM and RBF Support Vector Regression model.

Traceable pipeline

From monthly workbook to web forecast

The source is an institutional billing workbook, not a live substation feed. Each transformation is retained as code or an auditable artifact.

01

Billing source

ISELCO account-level monthly kWh records are read from the supplied workbook.

02

Clean and aggregate

Records are typed, deduplicated, flagged, and aggregated with meter-coverage controls.

03

Build daily series

Monthly totals are proportionally distributed across days and joined with weather and schedule context.

04

Train and compare

The LSTM-SVR cascade is trained chronologically and evaluated with ARIMA and ablation studies.

05

Serve results

FastAPI loads the operational artifacts and the authenticated dashboard requests forecast output.

Evaluation evidence

Results stay attached to their evaluation run

Training outcomes can change as data and model artifacts change. The workspace and generated reports remain the source for current metrics.

Evaluation capabilities

  • Chronological train, validation, and holdout handling preserves forecasting order.
  • Rolling-origin tests evaluate repeated recursive forecast windows.
  • ARIMA provides a classical baseline under documented comparison protocols.
  • Ablation tests examine the contribution of weather and schedule input groups.
  • RMSE, MAE, MAPE, R2, direction, and bias are available for model assessment.

Important boundaries

  • Daily consumption is reconstructed from monthly bills, not read from daily smart meters.
  • The academic calendar is a proxy rather than an official registrar feed.
  • Uncertainty bands are indicative and were not calibrated to true 95% coverage.
  • Anomaly flags identify unusual daily values; they do not detect outages or equipment failure.
  • Cost output is an estimate using a fixed reference rate, not a full utility tariff calculation.
